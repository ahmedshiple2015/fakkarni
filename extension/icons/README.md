# Bundled service icons

These 19 SVG identification marks are bundled locally. Fakkarni never requests a favicon or sends a vault domain to an icon service. An unknown service uses its title's first Unicode grapheme. The same assets serve the desktop and browser extension.

Source: [Simple Icons](https://github.com/simple-icons/simple-icons), pinned revision [`4d29a35c954699b389a834aacc97dd6e7e74143c`](https://github.com/simple-icons/simple-icons/tree/4d29a35c954699b389a834aacc97dd6e7e74143c), retrieved 2026-10-15. SVGs are unchanged upstream files; monochrome presentation is applied by the interface. The upstream project is CC0; the complete license and disclaimer are included here. Individual marks remain trademarks of their owners, and the upstream disclaimer explicitly distinguishes the collection license from rights in individual marks. These marks identify a user's saved service; they do not imply endorsement.

`upstream-metadata.json` retains each selected mark's original source and available brand-guideline links. None of these selected metadata entries specifies an individual license. Amazon and LinkedIn were not in the selected upstream revision and are not bundled. App identification is a small exact-title allowlist when the entry has no website; it does not scan installed programs or extract executable icons.

Assets contain only static SVG geometry and titles. Tests reject scripts, event attributes, styles, external references, and unexpected elements. Runtime resolution is an explicit domain allowlist with exact/dot-boundary matches; a title cannot override an unknown or malformed supplied website. An icon is identification artwork, not proof of a site's authenticity.
